# 🦉 الفبای من

اپلیکیشن آموزش الفبا و اعداد برای دانش‌آموزان **پایه اول دبستان** — کاملاً فارسی، کاملاً آفلاین.

[![Build APK & Release](https://github.com/wizardtcman-design/alefba/actions/workflows/build-apk.yml/badge.svg)](https://github.com/wizardtcman-design/alefba/actions/workflows/build-apk.yml)

## ✨ امکانات

### 🔤 حروف الفبا (به ترتیب کتاب درسی)
- ۳۲ حرف با واژه و تصویر مرتبط (اَبر ☁️، بادبادک 🪁، پرنده 🐦 و ...)
- تلفظ آفلاین هر حرف و واژه
- تمرین نوشتن با **نقطه‌چین** (کودک با انگشت روی نقاط می‌کشد)
- قفل مرحله‌ای: هر حرف بعد از کامل کردن حرف قبلی باز می‌شود

### 🔢 اعداد ۰ تا ۱۰۰
- نام فارسی هر عدد + تلفظ آفلاین
- شمارش تصویری (ایموجی تا ۲۰، نقطه‌های ده‌تایی برای اعداد بزرگ‌تر)
- تمرین نوشتن ارقام فارسی
- قفل گروهی: هر گروه ده‌تایی بعد از یادگیری ۶ عدد از گروه قبل باز می‌شود

### 🎮 شش بازی
| بازی | توضیح |
|---|---|
| 🔍 حرف را پیدا کن | پیدا کردن حرف درست بین ۴ گزینه |
| 🧩 پازل حرف | سوار کردن ۴ قطعه پازل حرف |
| 🧠 جفت‌های حافظه | جفت کردن حرف با تصویرش |
| ✋ بکش و بگذار | کامل کردن واژه با کشیدن حرف درست |
| 🍎 بشمار و انتخاب کن | شمردن شکل‌ها و کشیدن عدد درست به سبد |
| 🃏 جفت عدد | جفت کردن عدد با نقطه‌هایش |

### 📊 داشبورد والدین
- درصد پیشرفت کلی، حروف کامل‌شده، ستاره‌ها و تعداد بازی‌ها
- نقشه وضعیت تک‌تک حروف و گروه‌های اعداد
- پاک کردن امن پیشرفت با تاییدیه

### 🔊 کاملاً آفلاین
همه صداها داخل خود برنامه ذخیره شده‌اند؛ هیچ داده‌ای جمع نمی‌شود و نیازی به اینترنت نیست.

## 🚀 ساخت و انتشار (خودکار)

هر بار کد به شاخه `main` پوش شود، گیت‌هاب به‌صورت خودکار:

1. محیط Flutter را آماده می‌کند
2. فایل‌های پلتفرم اندروید را می‌سازد
3. APK نسخه Release را بیلد می‌کند
4. با نسخه داخل `pubspec.yaml` یک **GitHub Release** با فایل APK منتشر می‌کند

دانلود آخرین نسخه: صفحه [Releases](https://github.com/wizardtcman-design/alefba/releases)

### گردش کار «بروزرسانی»
1. شماره نسخه در `pubspec.yaml` بالا می‌رود (مثلاً `1.0.1+2`)
2. کد پوش می‌شود
3. Actions خودکار APK می‌سازد و Release جدید منتشر می‌کند

## 📲 نصب روی گوشی
فایل `alefba-vX.Y.Z.apk` را از Releases دانلود کنید؛ هنگام نصب گزینه «نصب از منابع ناشناس» را فعال کنید.
